# OISINT ロゴ素材

2026-08-15 に共有されたロゴ画像をブランド参照素材として保存しています。

## ファイル

- `reference/oisint-logo-horizontal-source.jpg`: 添付写真1の原本。横組みロゴ。
- `reference/oisint-logo-stacked-source.jpg`: 添付写真2の原本。シンボル＋ワードマークの縦組み。
- `oisint-logo-horizontal.png`: 原本の白余白をトリミングした、LP・ヘッダー用の表示素材（白背景・不透明）。
- `oisint-logo-stacked.png`: 原本の白余白をトリミングした、縦組み参照素材（白背景・不透明）。
- `oisint-logo-horizontal-transparent.png`: 横組みの白背景だけを透明化した表示用素材。実表示はこちらを使う。
- `oisint-logo-stacked-transparent.png`: 縦組みの白背景だけを透明化した表示用素材。実表示はこちらを使う。
- `../../public/ogp.png`: 静的共有カード用の 1200×630 PNG。店舗名・スコア・参加人数・検索文を含めない。

透過版は、外縁から連結する白背景のみを透明化し、ロゴ内部の閉じた白（虫眼鏡レンズ内・Oのカウンター）は
デザインの一部として白のまま残している。境界のアンチエイリアス画素は白マット除去（un-premultiply）で
alpha へ変換済みのため、濃色背景に置いても白いフチは出ない。不透明部分の RGB は元素材と完全一致する。

## 使用ルール

- 実表示（`app/index.tsx` ほか）は透過版 `oisint-logo-horizontal-transparent.png` / `oisint-logo-stacked-transparent.png` を参照する。白背景版は原本トリミングの正として保持し、削除・上書きしない。
- ロゴの形状・文字間・オレンジ／チャコールの色は変更しない。
- 比率を保ち、変形・過度なドロップシャドウ・AI風の発光処理を加えない。
- ロゴの周囲には白〜ウォームホワイトの余白を確保する。オレンジは行動喚起とロゴの視認性に限定して使う。

ブランドの基準色は、ロゴのオレンジ `#f4511e` とチャコール `#0b0d0f` を中心に、LPの背景 `#f7f6f3` と組み合わせる。

## OGP 画像の再生成手順

`public/ogp.png` は 2026-08-30 に OpenAI の画像生成で作成し、次の仕様を固定した。

```text
1200×630 の静的 OGP カード。ウォームホワイト背景、細いベージュ枠、中央寄せ。
既存 OISINT の虫眼鏡ロゴとワードマークを主役にし、
「根拠つきで、みんなで決める。」と「○ △ × ?」だけを配置する。
候補店名、スコア、人数、検索条件、人物、店舗写真、provider 由来素材は入れない。
```

再生成物は既存ファイルへ直接上書きせず、中央トリミング時の可読性と禁止情報の不在を目視確認する。
採用後は次を実行し、1200×630 であることと公開ファイルの差し替えをレビューする。

```bash
sips -g pixelWidth -g pixelHeight public/ogp.png
shasum -a 256 public/ogp.png
```
